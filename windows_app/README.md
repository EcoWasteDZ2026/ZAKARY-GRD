# ZAKARY GRD - Windows

نسخة سطح مكتب لنظام ZAKARY GRD تعمل على Windows دون محاكي أندرويد.

## البناء
يُبنى الملف التنفيذي عبر GitHub Actions باستخدام PyInstaller.
الناتج: `ZAKARY-GRD.exe`

## البيانات
تُحفظ البيانات محلياً في مجلد المستخدم داخل `AppData/Roaming/ZAKARY-GRD/records.json`.
تتوفر وظائف CSV والنسخ الاحتياطي والاستيراد JSON.
